# Plot a two-arm directional ROPE design

Plot a two-arm directional ROPE design

## Usage

``` r
# S3 method for class 'twoarm_rope_directional_onestage_design'
plot(
  x,
  which = c("default", "oc", "summary", "analysis_prior", "design_prior", "heatmap"),
  ...
)
```

## Arguments

- x:

  An object of class `twoarm_rope_directional_onestage_design`.

- which:

  Character, one of `"default"` (six-panel layout), `"oc"`, `"summary"`,
  `"analysis_prior"`, `"design_prior"`, or `"heatmap"`.

- ...:

  Currently unused.
