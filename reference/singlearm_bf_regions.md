# Construct strict single-arm Bayes factor evidence regions

Construct strict single-arm Bayes factor evidence regions

## Usage

``` r
singlearm_bf_regions(bfvals, k, k_ce = NULL)
```

## Details

Efficacy: BF01 \< k. Compelling evidence for H0: BF01 \> k_ce. Equality
at either threshold is inconclusive.
